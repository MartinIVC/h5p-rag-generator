# h5p-rag-generator
## Requisitos:
- Tener nodejs instalado.
- Seguir el paso a paso
## Paso a paso
Para conseguir correr el proyecto deben ejecutar lo siguiente:
```terminal
# 1. Clonar repositorio
git clone <URL-del-repositorio>

# 2. Configurar entorno
cd h5p-rag-generator/frontend
npm init
npm install electron --save-dev

# 3. Iniciar aplicacion
npm start
```
